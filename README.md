## Current Project

### 01. Secret Generator

A simple Express.js application that fetches a random secret from a public REST API and displays it using EJS.

**Concepts Covered**

- Axios GET requests
- Express.js
- EJS templating
- API response handling
- Dynamic rendering

## Tech Stack

- Node.js
- Express.js
- Axios
- EJS
- HTML
- CSS
