## Current Projects

### 01. Secret Generator

A simple Express.js application that fetches a random secret from a public REST API and displays it using EJS.

**Concepts Covered**

* Axios GET requests
* Express.js
* EJS templating
* API response handling
* Dynamic rendering

**Project Documentation**

[View Secret Generator README →](./01-secret-generator/README.md)

---

### 02. API Authentication

Demonstrates different ways of authenticating REST API requests using Axios.

**Concepts Covered**

* No Authentication
* Basic Authentication
* API Key Authentication
* Bearer Token Authentication
* Query Parameters
* Request Headers
* Axios Configuration

**Project Documentation**

[View API Authentication README →](./02-api-authentication/README.md)

---

### 03. REST API Demo

A complete REST API demonstration using Axios and Express.js with an interactive interface for performing different HTTP operations.

**Concepts Covered**

* GET requests
* POST requests
* PUT requests
* PATCH requests
* DELETE requests
* Bearer Token Authentication
* Request Body Handling
* Axios Configuration
* Express.js Routes
* EJS Forms
* REST API CRUD Operations

**HTTP Methods**

|   Method   | Purpose                    |
| :--------: | -------------------------- |
|   **GET**  | Retrieve a secret          |
|  **POST**  | Create a new secret        |
|   **PUT**  | Replace an existing secret |
|  **PATCH** | Update an existing secret  |
| **DELETE** | Delete a secret            |

**Project Documentation**

[View REST API Demo README →](./03-rest-api-demo/README.md)

## Tech Stack

|    Technology   | Purpose                                      |
| :-------------: | -------------------------------------------- |
|   **Node.js**   | JavaScript runtime                           |
|  **Express.js** | Web server and routing                       |
|    **Axios**    | HTTP client for REST API requests            |
|     **EJS**     | Server-side templating and dynamic rendering |
| **Body Parser** | Parsing incoming form data                   |
|     **HTML**    | Frontend structure                           |
|     **CSS**     | Frontend styling                             |
|  **REST APIs**  | External API communication                   |
